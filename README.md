# Leque Arquitetura - editable static site

This is a clean static rebuild generated from the public Wix site snapshot.

Files to edit:

- `index.html`: page structure and contact links.
- `styles.css`: visual styling.
- `data.js`: project text, details, covers, and gallery paths.
- `script.js`: project filtering and modal behavior.

The gallery images point to `../wix-snapshot/assets/images` to avoid duplicating hundreds of megabytes.
